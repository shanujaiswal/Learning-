What is the Constraint Validation API?

A browser-native API (checkValidity(), setCustomValidity(), the :valid/:invalid pseudo-classes) for validating form fields without JavaScript-only logic.

What is Shadow DOM?

An encapsulated DOM subtree attached to an element, with styles and markup isolated from the rest of the page — the basis for Web Components.
